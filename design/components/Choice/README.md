A choice is a radio button or a checkbox in a row with a border.

The row becomes gold when you select it.
Report reasons, the poll type, and display settings use it.

```jsx
<Choice name="kind" label="Multiple choice" defaultChecked />
<Choice name="kind" label="Yes / No" help="Results stay private until you reveal them." />
<Choice type="checkbox" label="Hide chat commands (!jump)" />
```
