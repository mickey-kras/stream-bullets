A topic row is one row in the topic list.

It has the category glyph, the Oswald title, the counts of likes, dislikes, and comments, and a chevron.
The title wraps. Do not cut it.
A selected row has a gold fill.

```jsx
<TopicRow title="Can AI run my homelab?" icon="cat-tech" likes={142} dislikes={18} comments={24} selected />
```
