An empty state is a panel with a dashed border.

It has a gold icon of 40px, a gold Oswald title, and a muted line of text.
It can have one action.

```jsx
<EmptyState icon="topics" title="Start a conversation." action={<Button variant="gold" font="display">Suggest the first topic</Button>}>
  Suggest a topic for Sunny's next stream.
</EmptyState>
```
