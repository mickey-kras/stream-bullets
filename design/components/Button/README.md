Use a button for each action in the interface.

Use one gold button in a view.

```jsx
<Button variant="gold" font="display" size="lg" icon="plus">Suggest a topic</Button>
<Button icon="eye">End & reveal</Button>
<Button variant="danger" icon="trash">Delete topic</Button>
```

| Property | Values |
| --- | --- |
| `variant` | `default`, `gold`, `danger`, `ghost`, or `link` |
| `font` | `display` sets Oswald in uppercase. The default is Figtree at weight 600. |
| `size` | `sm` is 32px high, `md` is 44px high, and `lg` is 48px high. |
| `landing` | Gives a large button with a hard `#a27a25` shadow. Use it only on the landing page. |
