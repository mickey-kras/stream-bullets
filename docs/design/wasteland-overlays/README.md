# Wasteland overlay mockups

This folder holds the visual direction for the merged chat (#663) and the character playground (#664).
The owner can change these files before implementation starts.

## Files

- `index.html`: the interactive mockup. Open it in a browser. It draws all art in code.
- `closeup-chat.png`: the merged chat at 1080p.
- `closeup-playground.png`: the character playground at 1080p.
- `screenshot-desktop.png`: the full mockup page.

## Status

- The art is placeholder art. It is not production art.
- The mockup does not use third-party game marks, characters, or trade dress.
- Some values in the demo are shorter than the values in the issues, so you can see the effects. Use the issue values in production.
- The decision lists in `index.html` show the open decisions.
