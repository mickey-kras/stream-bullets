# Repository guidance

Use `graphify-out/graph.json` as the local code and documentation map.
Get it from the `graph` branch or build it locally. See `docs/code-graph.md`.
Query it with the local Graphify CLI when available.
Use focused queries instead of reading the full JSON file.

The graph on the `graph` branch shows the latest `main`, not your branch.
Check the current source when the graph is stale or an answer is incomplete.
Do not commit the graph. Do not edit graph data by hand.
Do not use the cloud graph as the local snapshot.
